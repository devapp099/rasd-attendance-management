# رَصد | متابعة الحضور والغياب

تطبيق عربي لتسجيل الحضور، متابعة الغياب المتكرر، وتصدير التقارير. يحتوي ملف التطبيق على قائمة الطلبة مشفّرة باستخدام AES-256-GCM، ويطلب مفتاحًا منفصلًا عند الفتح.

## الاستخدام

1. افتح `index.html` عبر HTTPS (مثل GitHub Pages) أو من متصفح حديث يدعم Web Crypto.
2. أدخل مفتاح الفتح المحفوظ بصورة منفصلة.
3. سجّل الحالات، ونزّل نسخة احتياطية محلية بانتظام.

## حماية المفتاح والبيانات

- لا ترفع مفتاح الفتح أو النسخ الاحتياطية إلى GitHub.
- التشفير يحمي قائمة الأسماء في الشفرة العامة فقط ما دام المفتاح منفصلًا وقويًا. لا تضعي المفتاح في ملف التطبيق أو في متغير عام بالمستودع.
- سجلات الحضور والتواصل تحفظ محليًا في المتصفح. احفظي النسخة الاحتياطية في موقع خاص.
- تغيير قائمة الطلبة أو إعادة تشفيرها يحتاج تحديثًا منفصلًا لبيانات التشفير ومفتاحها.

## التخصيص

يمكن تعديل اسم المدرسة وحدود التنبيه من الإعدادات. حدود التنبيه قابلة للتعديل ولا تمثل قرارًا إداريًا تلقائيًا.
